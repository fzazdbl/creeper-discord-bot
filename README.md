# Creeper — Bot Discord pour serveur Minecraft

Bot Discord complet en **français** conçu pour un serveur Minecraft (classe BTS SIO).  
Il automatise la création de salons, de rôles, envoie des messages d’accueil et permet la lecture de musique YouTube via commandes slash.

---

## 🚀 Fonctionnalités principales

- Commande `/setup` : génère toutes les catégories, salons textuels et vocaux avec un thème Minecraft  
- Rôles automatiques : Admin, Modérateur, Joueur, Bot  
- Lecture de musique YouTube (`/play`, `/skip`, `/stop`, `/pause`, `/resume`)  
- Message d’accueil automatique dans un salon `📥-bienvenue`  
- Journalisation des actions dans un salon `#logs`  
- Commande `/help` pour afficher les commandes disponibles
